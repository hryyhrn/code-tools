# Token types - v1

## 1. Keywords

```
class
function
```
---

## 2. Identifiers

```
<string_identifier> (alphanumeric and underscore)
```
---

## 3. Visibility controllers

```
+ (Public fields and methods)
# (Protected fields and methods)
- (Private fields and methods)
```
---

## 4. Data types

```
void
int
char
bool
str
float
```
---

## 5. Punctuators

```
{}
()
,
:
```
---

## 6. Operators

```
=
```
---

## 7. Literals

```
<numeric>
"<string_literal>"
```
---

## 8. Comments

```
'
```
